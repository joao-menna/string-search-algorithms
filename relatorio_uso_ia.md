Foi utilizado o GitHub Copilot para auxiliar na implementação dos algoritmos de busca, bem como na estruturação do código e documentação. O projeto é uma aplicação de linha de comando que processa arquivos de texto e busca por padrões utilizando os algoritmos mencionados.

O roteiro do vídeo de demonstração teve ajuda do GitHub Copilot. O projeto também inclui a exportação de spans OpenTelemetry para análise de desempenho, e um dashboard para visualização histórica das execuções.

Os slides foram criados utilizando Gemini com `.pdf`, mas foram refeitos em `.md` com [Sli.dev](https://sli.dev) para usar recursos diferenciados que o Vue disponibiliza, como gráficos interativos e melhor formatação de código.

Para tudo eu busquei supervisionar a inteligência artificial, garantindo que as implementações fossem corretas e que a documentação fosse clara e precisa.
